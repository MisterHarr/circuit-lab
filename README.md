# Circuit Lab

Interactive 3D science learning website in development.

The project is intended to support electricity teaching across Year 4, Year 6 and KS3, with age-appropriate activities layered onto a shared interactive 3D environment.

## Current stage

The current site is a **school-access proof**, not the finished learning resource. It checks whether a pupil device/network can load:

- static HTML/CSS/JavaScript;
- WebGL;
- a same-origin local GLB file;
- touch/pointer rotation and Reset view.

No pupil data, analytics, accounts, remote APIs or runtime CDN dependencies are used by this test.

## Planned direction

The next stage moves into the real Circuit Lab experience: visual concept, image-generated component references, image-to-3D assets, Three.js integration, circuit interactions, scientific review and classroom evaluation.

Built through an AI-agent orchestration workflow for educational use and professional learning.
